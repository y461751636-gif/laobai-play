# 老白的游乐场

游戏、互动作品与视频的固定分享入口。

入口：<https://y461751636-gif.github.io/laobai-play/>

页面读取 `endpoint.json` 中的当前地址，再前往项目大厅。指定作品时，使用 `?path=` 传入以 `/projects/` 或 `/videos/` 开头的站内路径。

友友岛：<https://y461751636-gif.github.io/laobai-play/youyou-island.html>。该入口提供友友岛的标题、简介和小岛缩略图，并跳转到当前 NAS 的友友岛页面。

`endpoint.json` 由 NAS 同步程序维护，仅保存公开访问地址与更新时间。
